# Instalação — AI Software Factory

## Pré-requisitos

| Requisito | Verificação | Observação |
|-----------|------------|-----------|
| Windows 10/11 | — | Linux/macOS: só `install.sh` (CLI), sem Roo |
| PowerShell 5.1+ | `$PSVersionTable.PSVersion` | Disponível nativamente |
| Python 3.x no PATH | `python --version` | Necessário para MCP/RAG |
| Claude Code | `claude --version` | Para usar agentes com `@nome` |
| Roo Code/Cline (VS Code) | Extensão instalada | Opcional |

---

## Instalação rápida

```powershell
git clone https://github.com/<seu-usuario>/ai_software_factory.git
cd ai_software_factory
.\install.ps1
```

Abra um **novo terminal** depois da instalação — `FACTORY_ROOT` só fica disponível em sessões abertas após a configuração.

---

## O que o instalador faz

O `install.ps1` executa 8 fases em sequência:

### Fase 1 — FACTORY_ROOT
Define a variável de ambiente `FACTORY_ROOT` apontando para o diretório da factory. Usada por todos os scripts auxiliares.

### Fase 2 — Python
Detecta o interpretador Python disponível (`python`, `python3`, `py`).

### Fase 3 — Dependências MCP
Instala pacotes Python de `requirements.txt` via pip. Controlado por hash — só reinstala quando o arquivo muda ou `mcp` está ausente.

### Fase 4 — Agentes Claude Code
Gera 11 arquivos `.md` em `~/.claude/agents/`. Cada arquivo combina:
- `prompt.md` do agente
- Knowledge destilada do agente
- Bloco MCP com política MCP-first e tabela de ferramentas

Todos os arquivos têm header `AUTO-GENERATED BY ai_software_factory` — o uninstaller usa esse marcador para identificar o que pode remover com segurança.

### Fase 5 — Knowledge Base
Cria/atualiza `knowledge.db` (SQLite FTS5, ~7.000 documentos). Indexa todos os `.md` da factory. Pula se o DB é mais recente que todos os `.md`.

### Fase 6 — MCP Configuration
- Cria `.mcp.json` na raiz da factory
- Atualiza `~/.claude.json` (Claude Code global) com `mcpServers.knowledge`
- Atualiza Roo Code `mcp_settings.json` (se detectado)

### Fase 7 — Roo Code / Cline
Gera `roo/.roomodes` com 11 custom modes e `roo/.clinerules` com política MCP-first.

### Fase 8 — Scripts auxiliares
Gera/atualiza scripts em `~/.local/bin/` e na raiz da factory.

### Fase Final — MCP Health Check
Executa `test-mcp.ps1` para validar que o MCP está funcional.

---

## Idempotência

O instalador é **completamente idempotente**:

```powershell
.\install.ps1   # primeira execução: cria tudo
.\install.ps1   # segunda execução: SKIP em tudo que não mudou
```

Quando algo muda (editou um `prompt.md`, atualizou a factory), o instalador detecta a diferença e atualiza apenas o necessário.

---

## Opções do instalador

```powershell
.\install.ps1            # instalação normal
.\install.ps1 -ForceDeps # força reinstalação das dependências Python
```

---

## Verificar a instalação

```powershell
.\doctor.ps1      # diagnóstico completo (14 categorias)
.\test-mcp.ps1    # health check específico do MCP
```

## Instalação em Linux/macOS

Disponível via `install.sh` (somente Claude Code CLI, sem suporte Roo Code):

```bash
chmod +x install.sh
./install.sh
```
