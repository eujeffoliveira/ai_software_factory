# Troubleshooting — AI Software Factory

Problemas comuns e como resolver.

---

## Diagnóstico rápido

```powershell
cd $env:FACTORY_ROOT
.\doctor.ps1      # diagnóstico completo
.\test-mcp.ps1    # health check MCP
```

---

## Problemas de instalação

### `FACTORY_ROOT` não disponível após install.ps1

**Sintoma**: `$env:FACTORY_ROOT` está vazio.

**Causa**: A variável de ambiente de usuário foi definida, mas a sessão atual foi aberta antes disso.

**Fix**: Abra um novo terminal (PowerShell, Windows Terminal, etc.).

```powershell
# Verificar se está definido para sessões futuras
[System.Environment]::GetEnvironmentVariable("FACTORY_ROOT", "User")

# Usar manualmente nesta sessão
$env:FACTORY_ROOT = "C:\caminho\para\ai_software_factory"
```

---

### Python não encontrado

**Sintoma**: `[WARN] Python nao encontrado no PATH` durante o install.

**Fix**:
1. Instale Python 3.x em [python.org](https://python.org)
2. Durante a instalação, marque "Add Python to PATH"
3. Abra novo terminal e execute `python --version`
4. Execute `.\install.ps1` novamente

---

### Dependências pip falham

**Sintoma**: `[WARN] Falha ao instalar dependencias`.

**Fix**:
```powershell
# Instalar manualmente
pip install -r "$env:FACTORY_ROOT\tools\mcp-knowledge-search\requirements.txt"

# Ou forçar via install.ps1
.\install.ps1 -ForceDeps
```

## Problemas com MCP

### MCP não aparece em `/mcp` no Claude Code

**Sintoma**: Comando `/mcp` não lista o servidor `knowledge`.

**Possíveis causas**:

| Causa | Diagnóstico | Fix |
|-------|------------|-----|
| `~/.claude.json` não configurado | `.\doctor.ps1` → Seção 9 | `.\install.ps1` |
| `server.py` não encontrado | `.\test-mcp.ps1` → Check 2 | Verificar FACTORY_ROOT |
| `mcp` package não instalado | `.\test-mcp.ps1` → Check 5 | `.\install.ps1 -ForceDeps` |
| `knowledge.db` ausente | `.\test-mcp.ps1` → Check 3 | `.\update-knowledge.ps1` |
| Sessão antiga (cache) | — | Reinicie Claude Code |

**Diagnóstico completo**:
```powershell
.\test-mcp.ps1
```

---

### `health_check()` retorna error

**Sintoma**: Chamada ao MCP `health_check()` retorna `{"status": "error"}`.

**Fix por tipo de erro**:

| Razão no JSON | Fix |
|---------------|-----|
| `knowledge.db not found` | `.\update-knowledge.ps1` |
| `Table 'documents' not found` | `.\update-knowledge.ps1` |
| SQLite exception | `.\update-knowledge.ps1` |

---

### MCP configurado mas busca retorna 0 resultados

**Sintoma**: `search_knowledge("algo")` retorna `{"total": 0, "documents": []}`.

**Fix**:
```powershell
# Reindexar
cd $env:FACTORY_ROOT
.\update-knowledge.ps1

# Verificar contagem após reindexar
```

---

### Erro FTS: `no such column: documents`

**Causa**: Query usando tabela errada. A tabela FTS se chama `fts_docs`, não `documents`.

**Onde**: Pode aparecer em tools customizadas ou scripts que consultam o DB diretamente.

**Fix**: Use `FROM fts_docs WHERE fts_docs MATCH '...'` em vez de `FROM documents WHERE documents MATCH`.

## Problemas com agentes

### Agentes não aparecem no Claude Code

**Sintoma**: `@techlead` não é reconhecido.

**Fix**:
```powershell
# Verificar se os arquivos existem
ls "$env:USERPROFILE\.claude\agents\" | Where-Object Name -match "\.md$"

# Reinstalar
cd $env:FACTORY_ROOT
.\install.ps1
```

---

### Agente usa FACTORY_ROOT antigo (factory foi movida)

**Sintoma**: `.\doctor.ps1` mostra "Agentes com FACTORY_ROOT desatualizado".

**Fix**: Reinstale a partir do novo local:
```powershell
cd C:\novo\caminho\ai_software_factory
.\install.ps1
```

---

### MCP-first: agente não consulta o MCP

**Sintoma**: Agente inventa artefatos sem consultar o MCP.

**Fix**: Lembre o agente da política MCP-first:
```
Consulte o MCP (search_knowledge) antes de responder sobre skills, schemas ou templates.
```

Se o MCP estiver inativo: o agente deve declarar isso explicitamente (não silenciosamente).

## Problemas de desinstalação

### `uninstall.ps1` não remove agente (sem marcador)

**Sintoma**: Agente `X.md` existe mas não é removido.

**Causa**: Arquivo não tem o marcador `AUTO-GENERATED BY ai_software_factory` (pode ser um agente de outro projeto).

**Fix manual** (se tiver certeza que é da factory):
```powershell
Remove-Item "$env:USERPROFILE\.claude\agents\X.md"
```

---

### `~/.claude.json` ficou inválido após uninstall

**Sintoma**: Claude Code não inicia ou reporta erro de JSON.

**Fix**:
```powershell
# Verificar backups criados pelo install/uninstall
ls "$env:USERPROFILE\.claude.json.bak_*" | Sort-Object LastWriteTime -Descending

# Restaurar o mais recente
Copy-Item "$env:USERPROFILE\.claude.json.bak_YYYYMMDD_HHMMSS" "$env:USERPROFILE\.claude.json"
```

## Log do MCP

O servidor MCP escreve logs estruturados em:

```
<factory>/tools/mcp-knowledge-search/logs/mcp-knowledge.log
```

Cada linha é um JSON com `timestamp`, `event`, `duration_ms`, `status`.

```powershell
# Ver últimas entradas
Get-Content "$env:FACTORY_ROOT\tools\mcp-knowledge-search\logs\mcp-knowledge.log" | Select-Object -Last 20
```

## Reinstalação limpa

Se nada funcionar:

```powershell
cd $env:FACTORY_ROOT

# Desinstalar tudo
.\uninstall.ps1 -Full -Force

# Reinstalar do zero
.\install.ps1

# Diagnosticar
.\doctor.ps1
```
