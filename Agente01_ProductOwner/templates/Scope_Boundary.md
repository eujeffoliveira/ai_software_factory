## Scope Change Protocol

If a new request arises that is not in the in-scope list:

1. Tech Lead is notified by the requesting agent or stakeholder
2. Product Owner evaluates impact on existing stories, NFRs, and delivery timeline
3. PRD is revised (version bump) and Gate 1 review is requested again if scope is significantly impacted
4. No implementation proceeds until scope change is approved at Gate 1
