# Council Mediation Skill — Checklist

## Before Deliberation
- [ ] Council trigger identified (mandatory or recommended)
- [ ] Topic is specific and answerable — not vague
- [ ] At least 2 options provided (max 4)
- [ ] Each option has pros, cons, and risks populated
- [ ] Context includes current project state and constraints
- [ ] Urgency level set

## Deliberation Execution
- [ ] All 5 personas completed — none skipped
- [ ] Each persona analyzed all options (not just their preferred one)
- [ ] Contrarian identified the weakest point of each option
- [ ] First Principles stripped the problem to its core tradeoff
- [ ] Expansionist considered 3+ time horizons (immediate, 6 months, 2 years)
- [ ] Outsider referenced real-world industry patterns
- [ ] Executor assessed feasibility against current team/timeline

## Synthesis
- [ ] Consensus requires ≥ 3 personas agreeing explicitly
- [ ] Clashes documented as specific disagreements (not vague "they differ")
- [ ] Blind spots are gaps not covered by any option
- [ ] Recommendation references consensus points
- [ ] Recommendation acknowledges clashes explicitly

## Output Quality
- [ ] `one_thing_to_do_first` is a single, specific action
- [ ] `requires_human_decision` is true if: no 3-persona consensus, CRITICAL risk, irreversible action
- [ ] All 5 persona preferred options are populated
- [ ] Safeguards listed in recommendation are concrete, not generic

## Post-Council
- [ ] Council verdict incorporated into tollgate decision or State Ledger
- [ ] Human escalation triggered if `requires_human_decision = true`
- [ ] ADR created if verdict involves Golden Path deviation

## Runtime Knowledge Policy
- [ ] Skill does not depend on raw PDFs, raw books, `01-bibliografia/`, or `00-contexto/` at runtime.
- [ ] Council persona reasoning uses `knowledge/` distilled knowledge, not runtime PDF access.
