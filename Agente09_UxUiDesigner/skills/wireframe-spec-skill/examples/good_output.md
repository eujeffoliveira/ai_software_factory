The good_wireframe.md in the parent examples/ folder demonstrates correct output
from wireframe-spec-skill. Key qualities shown:

2. ASCII box drawing with named components in [brackets]
3. Repeated elements use "(repeat × N)" annotation
4. Component inventory listed below each wireframe
5. States table with all 4 states annotated
6. Mobile-specific behavior notes (hamburger, bottom sheet, load-more)
7. SCREEN-001, SCREEN-002 IDs assigned
8. Wireframe Index table at the end
9. No colors or fonts specified
10. Modal shown as bottom sheet on mobile, dialog on desktop
