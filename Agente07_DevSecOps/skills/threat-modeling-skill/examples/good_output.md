# Good Output — Threat Modeling Skill

See `Agente07_DevSecOps/examples/good_threat_model.md` for the full example.

**Key quality indicators:**
- All 6 STRIDE categories covered with specific, named threats
- Trust boundaries clearly defined with validation requirements
- Assets classified and justified
- Each threat has: ID, description, specific component, likelihood, impact, mitigation (with code reference), status
- Open threats explicitly listed with dispositions
- No vague mitigations like "we use NextAuth" — specific code patterns cited
