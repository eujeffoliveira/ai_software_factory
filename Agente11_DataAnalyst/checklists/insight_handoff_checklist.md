# Insight Handoff Checklist

- [ ] Each insight has a unique ID.
- [ ] Each insight cites metric IDs or source evidence.
- [ ] Each insight has a confidence label.
- [ ] Each caveat is attached to the relevant finding.
- [ ] Each recommendation has an owner.
- [ ] Each recommendation has a validation metric.
- [ ] Open questions are routed to a role or agent.
- [ ] Risks are classified as LOW, MEDIUM, HIGH, or CRITICAL.
- [ ] Dashboard needs are separated from analytical conclusions.
- [ ] Handoff package validates against `handoff_schema.json`.
