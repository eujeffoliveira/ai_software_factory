# Statistical Rigor Checklist

- [ ] The analysis distinguishes descriptive, diagnostic, predictive, and causal claims.
- [ ] Causal language is avoided unless a valid design is documented.
- [ ] Sample size is reported for all key comparisons.
- [ ] Segment comparisons include denominators.
- [ ] Multiple comparison risk is considered when many segments are ranked.
- [ ] Outliers are investigated before removal.
- [ ] Confidence label matches data quality and method strength.
- [ ] Alternative explanations are listed for major findings.
- [ ] Recommended follow-up validation is stated.
- [ ] The evidence required to change the recommendation is stated for high-impact decisions.
