# Exploratory Data Analysis Checklist

- [ ] Dataset grain is confirmed.
- [ ] Period covered is stated.
- [ ] Missingness is reviewed.
- [ ] Duplicate risk is reviewed.
- [ ] Freshness is reviewed.
- [ ] Validity and impossible values are reviewed.
- [ ] Join coverage is reviewed.
- [ ] Segment sample sizes are reviewed.
- [ ] Anomalies are listed.
- [ ] Bias and limitations are stated.
- [ ] EDA conclusion is ready, ready_with_caveats, or blocked.
