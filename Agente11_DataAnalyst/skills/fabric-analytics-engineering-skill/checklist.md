# Fabric Analytics Engineering Checklist

- [ ] Lakehouse, warehouse, Eventhouse, semantic model, or ontology role is explicit.
- [ ] Dataflow Gen2, notebook/Spark, T-SQL, KQL, or DAX surface is selected with rationale.
- [ ] Semantic model storage mode is explicit.
- [ ] Direct Lake fallback and refresh are documented when applicable.
- [ ] Star schema, relationships, scale settings, and performance risks are documented.
- [ ] Workspace/item/RLS/CLS/OLS/file access needs are documented.
- [ ] Sensitivity labels, Purview, endorsement, and downstream impact are documented.
- [ ] PBIP, version control, deployment pipeline, XMLA, templates, or shared model lifecycle needs are documented.
- [ ] AI readiness has clear names, descriptions, measures, relationships, and business vocabulary.
- [ ] Data engineering implementation tasks are routed to Agente10.
