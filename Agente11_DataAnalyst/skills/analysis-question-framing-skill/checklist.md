# Analysis Question Framing Checklist

- [ ] Decision supported is stated.
- [ ] Business question is one sentence.
- [ ] Population is defined.
- [ ] Exclusions are listed or marked none.
- [ ] Time window is defined.
- [ ] Comparison baseline is defined.
- [ ] Candidate metrics are listed.
- [ ] Available data sources are listed or marked unknown.
- [ ] Assumptions are separated from open questions.
- [ ] Blocking questions are marked.
