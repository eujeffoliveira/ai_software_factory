# Power BI Analytics Delivery Checklist

- [ ] Audience and decision supported are explicit.
- [ ] Source mode is selected: Import, DirectQuery, Direct Lake, mixed, or unknown.
- [ ] Metrics map to semantic model measures.
- [ ] Pages and visuals answer specific questions.
- [ ] Filters, slicers, interactions, navigation, tooltip, drillthrough, export, and mobile needs are specified.
- [ ] Accessibility requirements are specified.
- [ ] Refresh and gateway needs are documented.
- [ ] Workspace roles, item access, semantic model permissions, RLS, and sensitivity labels are documented.
- [ ] Distribution method is selected: report, app, dashboard, subscription, alert, or paginated report.
- [ ] QA criteria cover measure reconciliation, RLS, refresh, states, and accessibility.
