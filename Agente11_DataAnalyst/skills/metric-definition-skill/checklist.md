# Metric Definition Checklist

- [ ] Metric owner is defined.
- [ ] Decision supported is defined.
- [ ] Grain is defined.
- [ ] Numerator is defined when applicable.
- [ ] Denominator is defined for rates and ratios.
- [ ] Filters are defined.
- [ ] Exclusions are defined.
- [ ] Source fields are listed.
- [ ] Refresh cadence is listed.
- [ ] Validation rules are listed.
- [ ] Known caveats are listed.
- [ ] Status is complete, partial, or blocked.
